## What it does

The Funnel Chart turns a sequence of values into a responsive visual funnel. Each stage can have its own label, value, color, and gradient, while the component handles the sizing and layout automatically.

It supports both horizontal and vertical layouts, layered depth, curved or straight edges, animated entrances, hover interactions, patterns, grid styling, and flexible label layouts.

## Features

- Responsive sizing with Framer layout support
- Horizontal and vertical funnel orientations
- Up to 8 customizable stages
- Individual stage labels and values
- Individual stage colors
- Per-stage two-color gradients

- Layered depth effect
- Adjustable stage spacing

- Spread and grouped label layouts

- Hover highlighting and expansion

## Customization

### Funnel

Control the overall visual structure with:

- **Orientation** — Horizontal or vertical
- **Depth Layers** — Add layered shapes for more visual depth
- **Edges** — Choose curved or straight geometry
- **Stage Gap** — Control spacing between stages
- **Default Color** — Fallback color for stages without a custom color

### Stages

Each stage can be customized independently:

- Label
- Value
- Color
- Gradient on/off
- Gradient start color
- Gradient end color

The stage values determine the relative size of the funnel sections.

### Labels

Choose what information appears around each stage:

- Stage labels
- Numeric values
- Percentages
- Spread or grouped layouts
- Grouped label direction
- Grouped label alignment

### Patterns

Add subtle texture to the inner funnel layer with:

- None
- Diagonal
- Horizontal
- Vertical

Pattern color, opacity, and line width are independently adjustable.

### Grid

Add an optional visual grid behind the funnel:

- Grid on/off
- Alternating bands
- Band color
- Divider lines
- Line color
- Line opacity
- Line width

### Animation

Control the entrance and interaction behavior:

- Animation on/off
- Stagger delay
- Hover effect
- Hover scale
- Inactive-stage dimming

The component also respects reduced-motion preferences.

## Framer-ready

The component is designed to work directly inside Framer with responsive layout support and Property Controls.

It includes static-renderer handling so animation is not forced into static rendering environments, plus responsive measurement for different component sizes.

## Installation

1. Open the component in Framer.
2. Add a Code Component.
3. Copy the contents of [KarimSaifFunnelChart.tsx](./KarimSaifFunnelChart.tsx) into the component.
4. Add the component to your canvas.
5. Use the Property Controls to configure your funnel.

## Performance

The component uses SVG-based geometry rather than canvas rendering, keeping the visualization lightweight while still allowing layered shapes, gradients, patterns, and responsive scaling.

Animation is disabled for static rendering and can be disabled manually when a static presentation is preferred.
